# [Thực hành] Tạo Bố Cục 3 Cột bằng Bootstrap Grid và Flexbox

Bài thực hành sử dụng Bootstrap 5.3.3 và Font Awesome 6.5.2.

## Nội dung đã thực hiện

- Bố cục 3 cột với `row`, `col-12`, `col-md-4`.
- Căn giữa nội dung bằng `d-flex`, `justify-content-center`, `align-items-center`.
- Sử dụng `my-5`, `py-3`, `p-4` để tạo khoảng cách.
- Ẩn/hiện nội dung với `d-none d-md-block`.
- Bootstrap Carousel gồm 3 ảnh và nút chuyển slide.
- Font Awesome cho tiêu đề, cột và nút gửi.
- Bootstrap Form gồm họ tên, email, nội dung và nút Submit.
- Responsive trên desktop, tablet và mobile.

Mở `index.html` bằng trình duyệt để xem kết quả.
