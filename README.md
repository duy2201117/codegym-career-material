# CodeGym Career - Material Design Landing Page

Bài tập thực hành xây dựng Landing Page bằng **HTML, CSS, JavaScript, Bootstrap 4 và MDBootstrap 4.19.1**.

## Cấu trúc

```text
codegym-career-material/
├── index.html
├── style.css
└── script.js
```

## Cách chạy

Không cần cài Node.js hay chạy lệnh terminal.

1. Giải nén thư mục.
2. Mở `index.html` bằng Chrome/Edge.
3. Cần có Internet để tải CDN của Bootstrap, MDBootstrap, Font Awesome và Google Fonts.

## Nội dung đã có

- Navbar Material Design, responsive menu.
- Hero Section với CTA.
- Tổng quan chương trình.
- 6 Card lợi ích.
- Timeline lộ trình.
- Card khóa học Java/PHP.
- Career Service.
- Carousel testimonial demo.
- Form đăng ký có kiểm tra dữ liệu bằng JavaScript.
- Footer.
- Nút Back to Top.
- Responsive cho desktop, tablet và mobile.

## Lưu ý

- Đây là bài thực hành giao diện, form đăng ký **không gửi dữ liệu lên server**.
- Testimonial được ghi rõ là nội dung minh họa, không giả mạo phát ngôn của học viên thật.
- Nội dung được tham khảo và biên tập lại từ trang CodeGym Career theo yêu cầu đề bài.

## Cách đưa lên GitHub

1. Tạo repository mới trên GitHub, ví dụ: `codegym-career-material`.
2. Chọn **Add file → Upload files**.
3. Kéo 3 file `index.html`, `style.css`, `script.js` vào.
4. Chọn **Commit changes**.
5. Nếu muốn có link xem trực tiếp:
   - Vào **Settings → Pages**.
   - Ở **Build and deployment**, chọn `Deploy from a branch`.
   - Branch: `main`, folder: `/ (root)`.
   - Save.
6. Sau khi GitHub Pages deploy xong, copy URL và dán vào phần nộp bài.
