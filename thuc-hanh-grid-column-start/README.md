# Thực hành CSS - grid-column-start

Bài thực hành minh họa đầy đủ ba cách sử dụng thuộc tính `grid-column-start`:

- `grid-column-start: auto;`
- `grid-column-start: span 2;`
- `grid-column-start: 2;`

## File

- `index.html`
- `style.css`

Mở `index.html` bằng trình duyệt để xem kết quả của từng ví dụ.
