# Thực hành CSS | flex-grow Property

Bài thực hành minh họa thuộc tính `flex-grow` với 5 Flex Item.

## Nội dung

- Sử dụng `display: flex` cho Flex Container.
- Item 1, 3, 4, 5 dùng `flex-grow: 1`.
- Item 2 dùng `flex-grow: 3` để nhận nhiều phần không gian trống hơn.
- Minh họa tỉ lệ phân phối không gian `1 : 3 : 1 : 1 : 1`.
- Có giải thích thêm về `initial` và `inherit`.

## File

- `index.html`
- `style.css`

Mở `index.html` trên trình duyệt để xem kết quả.
