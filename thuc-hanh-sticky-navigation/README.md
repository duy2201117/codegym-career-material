# Thực hành: Tạo thanh điều hướng sticky khi cuộn trang

Bài thực hành sử dụng `position: sticky` để giữ thanh điều hướng ở đầu trang khi người dùng cuộn.

## Nội dung chính

- `position: sticky`
- `top: 0`
- `z-index: 1000`
- Menu ngang bằng Flexbox
- Hiệu ứng hover cho liên kết
- Nhiều section có chiều cao `100vh` để kiểm tra khi cuộn trang

Mở `index.html` bằng trình duyệt và cuộn xuống để quan sát hiệu ứng.
