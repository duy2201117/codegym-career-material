# Thực hành: Tạo Trang Giới Thiệu Doanh Nghiệp với Bootstrap

Bài thực hành sử dụng Bootstrap 5.3 để xây dựng một trang giới thiệu doanh nghiệp responsive.

## Nội dung chính

- Navbar responsive
- Hero Section
- About Section
- Services Section với Bootstrap Grid và Cards
- Contact Section
- Footer
- Bootstrap CDN và `bootstrap.bundle.min.js`

## Tệp chính

- `index.html`
- `style.css`

Mở `index.html` trên trình duyệt để kiểm tra giao diện desktop và mobile.
