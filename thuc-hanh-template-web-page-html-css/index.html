Web Technology

HTML là viết tắt của HyperText Markup Language. HTML được sử dụng để xây dựng cấu trúc cho trang web bằng các thẻ đánh dấu. Kết hợp cùng CSS, chúng ta có thể tạo ra những giao diện trực quan, dễ sử dụng và phù hợp với nhiều loại thiết bị.

C Programming

C là một ngôn ngữ lập trình thủ tục, được phát triển bởi Dennis Ritchie. Ngôn ngữ C nổi bật với khả năng truy cập bộ nhớ ở mức thấp, cú pháp gọn gàng và phù hợp cho lập trình hệ thống, hệ điều hành và trình biên dịch.

Java

Java là một trong những ngôn ngữ lập trình hướng đối tượng phổ biến. Mã Java được biên dịch thành bytecode và chạy trên Java Virtual Machine (JVM), nhờ đó chương trình có thể hoạt động trên nhiều hệ điều hành khác nhau.
