# [Thực hành] Template web page using HTML and CSS

Bài thực hành xây dựng một template trang web bằng HTML và CSS.

## Nội dung chính

- Navbar cố định phía trên với logo, menu và ô tìm kiếm.
- Section giới thiệu Web Technology.
- Section giới thiệu C Programming.
- Section giới thiệu Java kèm hình minh họa.
- Sử dụng Flexbox với `display: flex`, `justify-content`, `align-items`.
- Sử dụng `flex-direction: row-reverse` ở phần Java.
- Footer hiển thị thông tin bản quyền.
- Có responsive cho tablet và mobile.

## File

- `index.html`
- `style.css`

## Công nghệ

- HTML5
- CSS3
- Flexbox
