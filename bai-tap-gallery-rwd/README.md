# Bài tập: Tạo gallery đơn giản sử dụng RWD

Bài tập luyện tập Responsive Web Design bằng CSS Media Query.

## Yêu cầu đã thực hiện

- Màn hình lớn hơn 700px: 4 ảnh trên một dòng.
- Màn hình nhỏ hơn hoặc bằng 700px: 2 ảnh trên một dòng.
- Màn hình nhỏ hơn hoặc bằng 500px: 1 ảnh trên một dòng.
- Gallery có viền, mô tả ảnh và hiệu ứng hover.
- Sử dụng `clearfix` để xử lý các phần tử `float`.

Mở `index.html` trên trình duyệt và thay đổi độ rộng cửa sổ để kiểm tra responsive.
