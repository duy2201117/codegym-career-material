# Thực hành CSS | grid-row Property

Bài thực hành minh họa thuộc tính `grid-row` trong CSS Grid với 3 trường hợp:

- `grid-row: 1 / 3;`
- `grid-row: 2 / 4;`
- `grid-row: span 2;`

Grid được tạo gồm 3 cột và 3 hàng. Mỗi ví dụ giúp quan sát cách một Grid Item thay đổi vị trí bắt đầu, kết thúc hoặc kéo dài qua nhiều hàng.

Mở `index.html` bằng trình duyệt để xem kết quả.
