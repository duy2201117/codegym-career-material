# Thực hành: Xây dựng Landing Page với Bootstrap

Bài thực hành sử dụng Bootstrap 5.3 để xây dựng một Landing Page responsive.

## Nội dung chính

- Navbar responsive với nút toggler trên mobile.
- Hero Section với tiêu đề, mô tả và nút kêu gọi hành động.
- Bootstrap Grid System với 3 cột dịch vụ.
- Bootstrap Cards và Buttons.
- Footer.
- Responsive trên desktop và mobile.

## Chạy bài

Mở file `index.html` bằng trình duyệt có kết nối Internet để tải Bootstrap từ CDN.
