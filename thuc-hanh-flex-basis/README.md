# Thực hành CSS | flex-basis Property

Bài thực hành minh họa thuộc tính `flex-basis` trong Flexbox.

## Nội dung

- `flex-basis` với đơn vị `px`: 200px, 100px, 150px.
- `flex-direction: column` để thấy `flex-basis` tác động theo chiều dọc.
- `flex-basis: 50%`.
- Kết hợp `flex-basis: 100px` với `flex-grow` theo tỷ lệ 1 : 2 : 1.
- Ghi chú các giá trị `auto`, `initial`, `inherit`.

## File

- `index.html`
- `style.css`

Mở `index.html` bằng trình duyệt để xem kết quả.
