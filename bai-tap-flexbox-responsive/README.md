# Bài tập - Tạo bố cục responsive bằng CSS Flexbox

Bài tập xây dựng bố cục trang web responsive bằng CSS Flexbox.

## Thành phần
- Header
- Navigation
- Main Content
- Sidebar
- Footer

## Responsive
- Desktop: Main Content và Sidebar hiển thị cạnh nhau theo Flexbox.
- Mobile dưới 768px: Main Content và Sidebar xếp dọc.
- Màn hình nhỏ dưới 480px: menu điều hướng xếp dọc.

## File
- `index.html`
- `style.css`

Mở `index.html` bằng trình duyệt để kiểm tra giao diện.
