# Bài tập: Tạo layout với RWD

Bài tập sử dụng DIV và CSS để xây dựng bố cục responsive.

## Nội dung

- Header
- Menu điều hướng
- Sidebar trái
- Nội dung chính
- Sidebar phải
- Footer
- Responsive cho desktop, tablet và mobile bằng Media Queries

## Tệp

- `index.html`
- `style.css`

Mở `index.html` trên trình duyệt và thay đổi kích thước cửa sổ để kiểm tra Responsive Web Design.
