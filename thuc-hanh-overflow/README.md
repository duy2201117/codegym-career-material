# Thực hành - Quản lý nội dung bị tràn với Overflow

Bài thực hành sử dụng thuộc tính CSS `overflow` để kiểm soát nội dung vượt quá kích thước của phần tử.

## Yêu cầu chính

- Khối có `width: 300px` và `height: 100px`.
- Sử dụng `padding: 10px`.
- Nền `lightgray`.
- Sử dụng `overflow: auto` để tự động hiển thị thanh cuộn khi nội dung bị tràn.
