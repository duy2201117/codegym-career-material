# Thực hành tạo menu dọc dropdown

Bài thực hành HTML/CSS tạo menu dọc có menu con.

## Yêu cầu đã thực hiện

- Menu chính dạng dọc.
- Bỏ dấu đầu dòng của danh sách.
- Menu con dùng `position: absolute`.
- Menu con ẩn mặc định bằng `visibility: hidden`.
- Menu con hiển thị khi rê chuột vào mục cha bằng `:hover`.
- Liên kết màu trắng, nền menu màu đen và đổi màu khi hover.

Mở file `index.html` bằng trình duyệt để xem kết quả.
