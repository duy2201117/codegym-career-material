# Bài tập: Quản lý bố cục trang với overflow và float

Bài thực hành sử dụng `float`, `clear` và `overflow` để tạo bố cục hai cột và xử lý nội dung dài.

## Nội dung chính
- Cột trái: `float: left`
- Cột phải: `float: right`
- Xử lý float bằng `clear: both`
- Khối nội dung dài sử dụng `overflow: auto`
