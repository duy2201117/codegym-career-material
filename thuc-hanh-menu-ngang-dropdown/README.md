# Thực hành: Tạo menu ngang Dropdown

Bài thực hành tạo menu ngang hai cấp bằng HTML và CSS.

## Nội dung chính

- Menu cha hiển thị theo hàng ngang.
- Menu con được ẩn mặc định bằng `visibility: hidden`.
- Menu con hiển thị khi rê chuột vào mục cha bằng `:hover`.
- Menu con dùng `position: absolute` để xổ xuống bên dưới.
- Liên kết đổi nền sang màu đỏ khi hover.

## Chạy bài

Mở file `index.html` bằng trình duyệt.
