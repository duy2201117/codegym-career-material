# Bài tập: Tạo bố cục responsive bằng CSS Grid

Bài tập xây dựng bố cục trang web responsive bằng CSS Grid.

## Thành phần giao diện

- Header
- Navigation
- Main Content
- Sidebar
- Footer

## Kỹ thuật sử dụng

- `display: grid`
- `grid-template-columns`
- `grid-template-rows`
- `grid-template-areas`
- Media Queries

Trên desktop, Main Content và Sidebar hiển thị theo hai cột. Trên mobile, toàn bộ các phần được xếp dọc để hiển thị gọn gàng.

Mở `index.html` bằng trình duyệt để xem kết quả.
