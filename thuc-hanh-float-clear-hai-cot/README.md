# Thực hành: Tạo bố cục hai cột bằng Float và Clear

Bài thực hành tạo bố cục hai cột bằng CSS:

- Cột trái chiếm 60% và dùng `float: left`.
- Cột phải chiếm 38% và dùng `float: right`.
- Sử dụng pseudo-element `.container::after` với `clear: both` để xử lý float.
- Dùng `box-sizing: border-box` để padding không làm tràn tổng chiều rộng bố cục.

Mở `index.html` bằng trình duyệt để xem kết quả.
