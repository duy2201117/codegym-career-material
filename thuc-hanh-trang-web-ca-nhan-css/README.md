# Thực hành: Tạo trang web cá nhân với CSS

Bài thực hành HTML/CSS gồm:

- Tiêu đề chính
- Ảnh đại diện `avatar.jpg`
- Phần giới thiệu bản thân
- Danh sách sở thích
- Mục tiêu học tập
- Bảng thông tin liên hệ
- Sử dụng `border`, `background-color`, `background-image`, `color` và nhiều bộ chọn CSS

## Chạy bài

Mở file `index.html` bằng trình duyệt.
