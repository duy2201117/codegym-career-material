# Thực hành CSS - flex-flow

Bài thực hành minh họa thuộc tính `flex-flow`, là shorthand của `flex-direction` và `flex-wrap`.

## Ví dụ

- `flex-flow: row nowrap;`
- `flex-flow: row-reverse nowrap;`

## File

- `index.html`
- `style.css`

Mở `index.html` trên trình duyệt để quan sát sự khác nhau giữa hai cách sắp xếp Flex Item.
