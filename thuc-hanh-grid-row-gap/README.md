# Thực hành CSS | grid-row-gap Property

Bài thực hành minh họa đầy đủ các nhóm giá trị của `grid-row-gap`:

- `length`: `grid-row-gap: 20px;`
- `percentage`: `grid-row-gap: 5%;`
- `global-values`: `initial`, `inherit`, `unset`

Trong CSS hiện đại, có thể dùng `row-gap` thay cho `grid-row-gap`.

Mở `index.html` bằng trình duyệt để xem kết quả.
