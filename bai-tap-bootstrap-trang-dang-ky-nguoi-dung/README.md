# [Bài tập] Tạo Trang Đăng Ký Người Dùng

Bài tập sử dụng Bootstrap 5 để xây dựng trang đăng ký tài khoản responsive.

## Nội dung đã thực hiện

- Bootstrap Carousel hiển thị 3 lợi ích của dịch vụ.
- Bootstrap Grid chia giao diện thành 2 cột trên desktop và 1 cột trên mobile.
- Form đăng ký gồm:
  - Họ và tên.
  - Email.
  - Mật khẩu.
  - Xác nhận mật khẩu.
- Sử dụng `form-control`, `input-group`, `form-check`, `btn-primary`.
- Ưu tiên sử dụng lớp Bootstrap, chỉ dùng một ít CSS để điều chỉnh chiều cao ảnh Carousel.
- Giao diện responsive trên desktop, tablet và mobile.

## Công nghệ

- HTML5
- CSS3
- Bootstrap 5.3.3
