# Thực hành: Xây dựng bố cục trang web với CSS Grid

Bài thực hành sử dụng CSS Grid để xây dựng bố cục trang web hoàn chỉnh gồm:

- Header
- Sidebar
- Main Content
- Footer
- `grid-template-columns`
- `grid-template-rows`
- `grid-template-areas`
- Responsive bằng Media Queries

## Tệp chính

- `index.html`
- `style.css`

Mở `index.html` bằng trình duyệt để xem kết quả. Trên màn hình nhỏ hơn 768px, bố cục chuyển từ hai cột sang một cột theo chiều dọc.
