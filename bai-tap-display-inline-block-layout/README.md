# Bài tập: Xây dựng bố cục trang web với display và inline-block

Bài tập luyện tập sử dụng các thuộc tính CSS:

- `display: block`
- `display: inline-block`
- `width`
- `max-width`

Trang gồm tiêu đề, thanh điều hướng 4 liên kết, phần nội dung 3 cột và footer.

## Tệp chính

- `index.html`
- `style.css`

Mở `index.html` bằng trình duyệt để xem kết quả.
