# Thực hành Bootstrap Navbar

Bài thực hành tạo thanh điều hướng responsive bằng Bootstrap 5.3.

## Nội dung

- Sử dụng Bootstrap CDN.
- Navbar tối màu với thương hiệu `MyWebsite`.
- Menu gồm Home, About, Services và Contact.
- Services có dropdown gồm Web Design và SEO.
- Navbar có nút toggler khi hiển thị trên thiết bị di động.
- Bootstrap Bundle JS được nhúng để dropdown và collapse hoạt động.

Mở `index.html` trên trình duyệt để kiểm tra giao diện desktop và mobile.
