# Thực hành - Xây dựng Trang Chủ với Bootstrap

Bài thực hành sử dụng Bootstrap 5.3.3 để xây dựng một trang chủ responsive.

## Nội dung chính

- Navbar responsive với Font Awesome.
- Carousel ảnh ở Hero Section.
- Sử dụng Display Property và Flexbox với `d-flex`, `justify-content-center`, `align-items-center`.
- Sử dụng Margin & Padding với các utility class như `mt-*`, `mb-*`, `py-*`, `px-*`.
- Khu vực dịch vụ bằng Bootstrap Grid và Cards.
- Contact Form sử dụng `form-control` và nút `btn-primary`.
- Footer.
- Responsive trên desktop, tablet và mobile.

## File

- `index.html`
- `style.css`

Mở `index.html` trên trình duyệt để xem kết quả.
