# Bài tập: Thiết kế Trang Đăng Ký với Bootstrap Forms

Bài tập sử dụng Bootstrap 5.3 để xây dựng form đăng ký người dùng responsive.

## Nội dung chính

- Họ và tên
- Email
- Mật khẩu
- Xác nhận mật khẩu
- Giới tính bằng Radio Button
- Sở thích bằng Checkbox
- Quốc gia bằng Select
- Nút Submit với `btn-primary`
- Sử dụng `form-control`, `form-select`, `form-check`
- Sử dụng `text-muted`, `text-center`
- Responsive trên desktop và mobile

## Tệp chính

- `index.html`
- `style.css`

Mở `index.html` bằng trình duyệt để xem kết quả.
