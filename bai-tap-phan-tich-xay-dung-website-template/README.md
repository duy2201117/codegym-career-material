# [Bài tập] Phân tích và Xây dựng Cấu Trúc Website Template

## Nội dung bài làm

Bài tập gồm 2 phần:

1. Phân tích cấu trúc website thực tế: **Apple Việt Nam**.
2. Xây dựng lại bố cục tương tự bằng HTML & CSS, chỉ tập trung vào cấu trúc và cách tổ chức giao diện.

## Các file

- `index.html`: bố cục website mẫu.
- `style.css`: CSS cho giao diện và responsive.
- `phan-tich.md`: phần phân tích Header, Navigation, Content Section, Footer.

## Yêu cầu đã thực hiện

- Header có tiêu đề/nhận diện website.
- Navigation Menu có ít nhất 4 mục.
- Content Section có phần mô tả và khu vực sản phẩm.
- Footer có bản quyền.
- CSS có Flexbox, Grid, khoảng cách và responsive.

## Ảnh chụp trang web gốc

Bài tập yêu cầu ảnh chụp màn hình website gốc đã phân tích. Hãy mở **Apple Việt Nam** trên trình duyệt và chụp bằng `Win + Shift + S`, sau đó lưu vào thư mục `images` trước khi nộp nếu giáo viên yêu cầu ảnh đính kèm trực tiếp.

> Lưu ý: không nên dùng ảnh minh họa tạo lại để thay thế ảnh chụp trình duyệt thật.
