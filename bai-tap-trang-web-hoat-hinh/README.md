# Bài tập: Phát triển trang web xem hoạt hình trực tuyến

Website thực hành HTML/CSS/JavaScript với bố cục xem phim hoạt hình.

## Chức năng đã hoàn thành

- Header cố định và logo bên trái.
- Head-link điều hướng.
- Left Content hiển thị danh sách phim.
- Right Content hiển thị video đang xem.
- Footer bản quyền.
- Dùng cả thẻ `<video>` và YouTube `<iframe>`.
- Tìm kiếm phim theo tên.
- Sắp xếp theo mới cập nhật hoặc nhiều lượt xem.
- Hiệu ứng hover cho liên kết và thẻ phim.
- Responsive cho PC, tablet và điện thoại.
- Không chèn banner/quảng cáo trong giao diện website.
- YouTube được nhúng bằng miền `youtube-nocookie.com` để sử dụng Privacy Enhanced Mode.

## Các file

- `index.html`
- `style.css`
- `script.js`

## Chạy bài

Mở `index.html` bằng trình duyệt.

> Lưu ý: Video YouTube là nội dung do nền tảng bên ngoài cung cấp; việc phát quảng cáo trong trình phát nhúng phụ thuộc vào YouTube.
