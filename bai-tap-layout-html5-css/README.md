# Bài tập: Tạo layout với các thẻ HTML5 và CSS

Bài thực hành xây dựng bố cục trang web bằng các thẻ HTML5 ngữ nghĩa:

- `header`
- `nav`
- `section`
- `article`
- `aside`
- `footer`

## File

- `index.html`: cấu trúc HTML5 semantic layout.
- `style.css`: định dạng giao diện và responsive cơ bản.

Mở `index.html` bằng trình duyệt để xem kết quả.
