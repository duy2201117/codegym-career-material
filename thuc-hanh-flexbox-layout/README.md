# Thực hành - Xây dựng bố cục trang web với CSS Flexbox

Bài thực hành xây dựng bố cục website responsive bằng CSS Flexbox.

## Thành phần
- Header
- Navigation
- Main Content
- Sidebar
- Footer

## Kỹ thuật sử dụng
- `display: flex`
- `flex-direction`
- `flex-grow` / `flex`
- `flex-wrap`
- Media Query responsive

## Responsive
- Desktop: Main Content và Sidebar nằm cạnh nhau theo tỷ lệ 3:1.
- Mobile dưới 768px: Main Content và Sidebar xếp dọc.

Mở `index.html` bằng trình duyệt để xem kết quả.
