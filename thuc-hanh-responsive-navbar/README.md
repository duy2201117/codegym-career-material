# Thực hành: Tạo thanh điều hướng responsive

Bài thực hành xây dựng Responsive Navbar bằng HTML, CSS và JavaScript.

## Nội dung chính

- Desktop hiển thị menu ngang bằng Flexbox.
- Mobile dưới 768px ẩn menu và hiển thị biểu tượng ☰.
- JavaScript thêm/xóa class `active` để mở/đóng menu.
- Sử dụng Media Queries để responsive.
- Có hiệu ứng hover cho liên kết.

## File

- `index.html`
- `style.css`
- `script.js`

Mở `index.html` bằng trình duyệt và thu nhỏ cửa sổ để kiểm tra giao diện mobile.
