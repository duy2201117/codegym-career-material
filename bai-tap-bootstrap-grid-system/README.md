# Bài tập: Thiết kế Trang Web với Bootstrap Grid System

Bài tập sử dụng Bootstrap 5.3 để xây dựng bố cục responsive gồm:

- Header
- Bootstrap Navbar có dropdown
- Bootstrap Container
- Grid System với `row` và `col-*`
- Main Content
- Sidebar
- Footer
- Responsive desktop/mobile

## Responsive

- Màn hình từ 992px trở lên: Main Content và Sidebar hiển thị thành 2 cột theo tỷ lệ 8/4.
- Màn hình nhỏ hơn 992px: Main Content và Sidebar xếp thành 1 cột.

## Tệp chính

- `index.html`
- `style.css`

Mở `index.html` bằng trình duyệt để kiểm tra giao diện và dropdown của Navbar.
