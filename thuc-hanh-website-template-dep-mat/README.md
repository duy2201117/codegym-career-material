# [Thực hành] Tạo Website Template Có Giao Diện Đẹp Mắt

Bài thực hành xây dựng một website template hiện đại bằng HTML và CSS.

## Nội dung chính

- Header có ảnh nền và hiệu ứng blur.
- Navigation Menu cố định/sticky khi cuộn.
- Hiệu ứng hover cho menu, nút và card.
- Card Layout sử dụng CSS Grid.
- Bố cục Flexbox cho phần giới thiệu, CTA và Footer.
- Footer 2 cột, sử dụng dấu chấm (•) để phân cấp nội dung.
- Thiết kế responsive cho desktop, tablet và mobile.
- Ảnh minh họa được lưu trực tiếp trong thư mục `images` dưới dạng SVG, không phụ thuộc nguồn ảnh ngoài.

## Cấu trúc

```text
thuc-hanh-website-template-dep-mat/
├── index.html
├── README.md
├── css/
│   └── style.css
└── images/
    ├── banner.svg
    ├── service1.svg
    ├── service2.svg
    └── service3.svg
```

Mở `index.html` bằng trình duyệt để xem kết quả.
