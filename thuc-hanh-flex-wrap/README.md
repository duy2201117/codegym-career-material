# Thực hành CSS | flex-wrap Property

Bài thực hành minh họa đầy đủ các giá trị thường dùng của thuộc tính `flex-wrap` trong Flexbox.

## Nội dung

- `flex-wrap: nowrap;`
- `flex-wrap: wrap;`
- `flex-wrap: wrap-reverse;`
- `flex-wrap: initial;`

## File

- `index.html`
- `style.css`

Mở `index.html` bằng trình duyệt để quan sát sự khác nhau giữa các giá trị của `flex-wrap`.
