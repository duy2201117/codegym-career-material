# Bài tập: Tạo giao diện giản lược của trang chủ

Bài tập thực hành thuộc tính `position` và Flexbox.

## Nội dung

- Header cố định bằng `position: fixed`
- Sử dụng `top`, `left`, `width: 100%`
- Sử dụng `z-index: 1000`
- Bố cục 3 cột bằng Flexbox
- Sidebar trái rộng 200px
- Nội dung chính dùng `flex-grow: 1`
- Sidebar phải rộng 200px
- Thêm `padding-top` cho `body` để nội dung không bị header che
- Trang đủ dài để cuộn và kiểm tra fixed header

## Chạy bài

Mở file `index.html` bằng trình duyệt và cuộn trang để kiểm tra header luôn cố định ở phía trên.
