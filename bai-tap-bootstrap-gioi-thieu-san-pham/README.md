# Bài tập: Thiết kế Trang Giới Thiệu Sản Phẩm

Trang giới thiệu sản phẩm được xây dựng bằng Bootstrap 5.3.3 theo phong cách trang sản phẩm hiện đại.

## Nội dung chính
- Bootstrap Grid System với `container`, `row`, `col-*`.
- Sử dụng các utility class về `display`, `margin`, `padding`.
- Sử dụng Flexbox với `d-flex`, `justify-content-*`, `align-items-*`.
- Minh họa `display: contents` trong phần thông số sản phẩm.
- Sử dụng Font Awesome để hiển thị icon.
- Có Navbar, Hero sản phẩm, tính năng, thông số, CTA và Footer.
- Responsive trên desktop, tablet và mobile.
- Hạn chế CSS riêng, ưu tiên sử dụng Bootstrap.

Mở `index.html` trên trình duyệt để xem kết quả.
