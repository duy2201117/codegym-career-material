# Thực hành CSS | grid-template-columns Property

Bài thực hành minh họa cách sử dụng thuộc tính `grid-template-columns` trong CSS Grid.

## Nội dung

- Ví dụ 1: `grid-template-columns: 1fr 1fr 1fr;` tạo 3 cột bằng nhau.
- Ví dụ 2: `grid-template-columns: 100px 200px 1fr;` tạo 3 cột có kích thước khác nhau.
- Có sử dụng `display: grid` và `gap` để tạo khoảng cách giữa các ô.
