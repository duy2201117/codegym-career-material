# Thực hành: Tạo bố cục Fixed Header và Fixed Footer

Bài thực hành CSS về `position: fixed`.

## Nội dung

- Fixed menu ở phía trên với `top: 0` và `width: 100%`.
- Nội dung trang đủ dài để kiểm tra khi cuộn.
- Fixed footer ở phía dưới với `bottom: 0`.
- Có hiệu ứng hover cho các liên kết menu.

Mở `index.html` bằng trình duyệt và cuộn trang để quan sát hiệu ứng.
