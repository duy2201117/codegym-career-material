# Thực hành: Tạo bố cục cơ bản

Bài thực hành xây dựng layout trang web bằng `div` và CSS với đầy đủ các vùng:

- `#main`
- `#head`
- `#head-link`
- `#left`
- `#content`
- `#right`
- `#footer`

Bố cục sử dụng `float` để chia khu vực trái, nội dung chính và khu vực phải. Footer dùng `clear: both` để nằm đúng dưới các cột.

Mở `index.html` bằng trình duyệt để xem kết quả.
