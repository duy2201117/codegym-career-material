# Thực hành CSS | grid-gap Property

Bài thực hành minh họa đầy đủ 2 trường hợp của `grid-gap`:

- `grid-gap: 20px;` — khoảng cách hàng và cột bằng nhau.
- `grid-gap: 30px 10px;` — khoảng cách hàng và cột khác nhau.

Trong CSS hiện đại, có thể dùng `gap` thay cho `grid-gap`.

Mở `index.html` trên trình duyệt để kiểm tra kết quả.
