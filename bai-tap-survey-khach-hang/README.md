# Bài tập: Tạo form lấy survey khách hàng

Bài tập thực hành HTML/CSS tạo form khảo sát khách hàng theo mẫu Market Research Survey.

## Nội dung

- Chọn độ tuổi
- Chọn mức thu nhập
- Chọn giới tính
- Chọn sản phẩm đã mua
- Chọn tần suất sử dụng
- Nhập mức giá mong muốn
- Nhập tính năng mong muốn
- Đánh giá mức độ đồng ý với các tiêu chí
- Nút Submit

## File

- `index.html`
- `style.css`

Mở file `index.html` bằng trình duyệt để xem kết quả.
