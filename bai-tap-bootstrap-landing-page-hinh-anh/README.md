# Bài tập: Tạo Landing Page với Bootstrap và Hình Ảnh

Bài tập sử dụng Bootstrap 5 để xây dựng Landing Page responsive.

## Nội dung chính

- Navbar responsive.
- Hero/Banner tự xây dựng bằng Bootstrap 5 và CSS, không sử dụng Jumbotron.
- Hình ảnh nổi bật và ảnh giới thiệu responsive với `img-fluid`.
- Bootstrap Grid System với `container`, `row`, `col-*`.
- Phần giới thiệu gồm hình ảnh và nội dung.
- 4 tính năng dạng cột/card.
- Nút CTA sử dụng `btn-primary`, `btn-light`, `btn-lg`.
- Footer.
- Responsive cho desktop, tablet và mobile.

## File

- `index.html`
- `style.css`

Mở `index.html` bằng trình duyệt để xem kết quả.
