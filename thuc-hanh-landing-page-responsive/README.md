# Thực hành: Xây dựng Landing Page Responsive

Bài thực hành xây dựng landing page bằng HTML và CSS, hiển thị tốt trên desktop và mobile.

## Thành phần chính

- Header và thanh điều hướng
- Hero section
- Khu vực dịch vụ
- Khu vực testimonial
- Footer
- Flexbox
- CSS Grid
- Media Queries
- Responsive cho tablet và điện thoại

Mở `index.html` bằng trình duyệt và thay đổi kích thước cửa sổ để kiểm tra giao diện responsive.
